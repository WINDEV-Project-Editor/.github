# WINDEV

> WINDEV keeps windows, data, and reports on one Windows desk: open the project editor, build with window RAD, and leave HFSQL data on the same Windows app.

## Four Beats

1. **Name the project.** Give the WINDEV Windows app a short title before you draw a window.
2. **Pin the live windows.** Keep current screens on WINDEV project editor and leave unused windows aside.
3. **Check the RAD.** Read WINDEV window RAD before you move HFSQL data.
4. **Keep data close.** Leave WINDEV HFSQL data on the same WINDEV Windows app.
5. **Close the loop.** Clear finished windows so the next WINDEV visit does not start with a search.

## First Questions

**Does WINDEV replace every other program?**
No. WINDEV sits beside the editor, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate WINDEV profile.

**What should a new user try first?**
One small WINDEV window today, then the same HFSQL data tomorrow.

**Does HFSQL data leave the Windows app?**
No. WINDEV HFSQL data stays with WINDEV window RAD on that project.

## Who Sits Down at WINDEV

- **Project editor** — windows stay on WINDEV project editor.
- **Window RAD** — screens stay on WINDEV window RAD.
- **HFSQL data** — tables stay on WINDEV HFSQL data.
- **Windows app** — the name stays on one WINDEV project.
- **Shared desk** — each WINDEV profile keeps its own pins.
- **Handoff** — the next person can read the WINDEV note without a tour.

## Field Note

WINDEV is easier to trust when the project editor stays smaller than the folder it came from. A named Windows app shows what is active, the window pins show what you will build today, and the closing note tells the next person which RAD screen changed.

The same loop fits a single window, a short report, or a desk shared by two people. Open the last WINDEV project, finish one window, and leave fewer split files than you found.

## One Real Pass

Pick a project that already has a name. Open it in WINDEV, keep only those windows on the project editor, and finish one RAD screen you can see.
